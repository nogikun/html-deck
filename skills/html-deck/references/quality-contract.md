# 品質契約 — 1600x900 で読める形の数値

しきい値の実体は `assets/gates.json`。ここはその**根拠**。
根拠を知らずに数値だけ守ると、外すべき場面で外せない。

## なぜ 1600x900 固定なのか

ビューアは内部を常に 1600x900 で描き、ウィンドウに合わせて全体へ同じ倍率を掛ける
(`scale = min(幅/1600, 高さ/900)`)。だから **CSS を可変にする必要がない。**
`clamp()` も `cqh` も使わず px で書き切ってよく、そのほうが実測値と指定値が一致して
評価ループが安定する。

代償として、小さいウィンドウでは文字も小さくなる。保証しているのは
「どの画面でもレイアウトが同一」であって「どの画面でも読める」ではない。
倍率 0.45 未満はビューアが全画面表示を促す。発表環境としては 0.45 未満を許容しない。

## 文字サイズ

検査は文字を2段階に分けて見る。**読ませる文**と、**目印としてのラベル**では
必要な大きさが違うからで、同じ下限を当てると装飾ラベルの修正でループの枠が埋まる。

| 段階 | 何が当たるか | 目安 | 下限 |
| --- | --- | --- | --- |
| 本文 | 25文字以上の地の文 | 24px | **22px** (18px未満は block) |
| ラベル | 25文字未満の見出し語・数値・キャプション | 18–20px | **18px** |
| 細字 | `.slide-footer` `.source` `.caption` `.footnote` `figcaption` 内 | 18px | **14px** |
| 全体 | どんな文字も | — | **14px (絶対下限)** |

| 用途 | 目安 |
| --- | --- |
| デッキタイトル / 数字1つを見せる枚 | 80–96px |
| スライド見出し (h1/h2) | 48–72px、本文の 2.2倍以上 |
| 小見出し (h3) | 32–40px |
| リード文 | 28–32px |

下限の根拠は視力ではなく**縮小耐性**。会議室の共有画面やWeb埋め込みで倍率 0.5 まで
落ちると 22px は 11px になる。これ以下は「読めるが読まれない」状態になる。

細字の枠は出典と注記のためにある。**本文を `.caption` で包んで下限から逃げない。**
検査は通っても、絵を見る批評担当が読めない文字として落とす。

サイズ段階は **7種類まで**。段階が多いほど「どれが重要か」の手がかりが薄れる。
見出しと本文の比が 2.2倍未満だと、視線の入口が決まらない。

日本語の見出しは `word-break: auto-phrase` で文節ごとに折る。これがないと
「ではな / く」のように語の途中で改行され、読み直しが起きる。`text-wrap: balance` と
併せて theme.css の見出しに入れてある。

## 1枚あたりの情報量

- 日本語 **420文字**まで。超えると3秒では読めない
- 箇条書きは **6項目**まで、1項目 **2行**まで
- 1行の長さは日本語 **46文字**、英語 **82文字**まで。超えると行頭に戻れなくなる
- 文字ブロックの面積が画面の 42% を超えたら、削るか2枚に割る

これらは block ではなく review。長い引用や表を意図的に見せる枚では正当に超える。
超えたときは deck.md の `accepted` に理由を書き、批評担当に判断を渡す。

## 余白

- 外周 padding は 48px 以上 (テンプレートは左右80px / 上56px / 下48px)
- 安全余白 48px の内側に本文を収める。プロジェクタの端切れとブラウザのUI被りに効く
- **どの要素も 0–1600 / 0–900 の外へ出ない。** 出たら block。
  `overflow:hidden` で隠れているだけの状態は、PDF出力や別環境で表に出る

## 色

- 本文と背景のコントラスト比 **4.5:1** 以上。大きい文字 (32px以上、または24px以上の太字) は **3.0:1** 以上
- 色を **4〜6色**に絞る。役割で名前を付ける (`--accent` であって `--blue` ではない)
- 強調色は1枚に1箇所。2箇所以上あるとどちらも強調でなくなる
- 色だけで区別しない。凡例・ラベル・形も併記する (色覚特性とモノクロ印刷)
- **theme.css のトークンにない色を各スライドで作らない。** 検査は `palette_drift` として
  全部拾う。1枚の都合で増やした色は、デッキ全体の声を割る

## 書体

外部フォントは読み込めない (CSP と オフライン配布)。選択肢は2つ。

1. ローカルにある face で組む。macOS なら Hiragino Kaku Gothic ProN / Hiragino Mincho /
   Yu Gothic / Helvetica Neue / Avenir Next / Optima / Georgia / Baskerville /
   Futura / SF Mono / Menlo あたり。**配布先にも同じ face があるとは限らない**ので、
   スタックの末尾に必ず `system-ui, sans-serif` を置く
2. woff2 を `deck/fonts/` に置き、`@font-face` で相対参照する。ライセンスを確認する

配布先の環境が固定できないなら、フォント差で崩れない**固定PDF**を納品形式にする。

## 安全性・配布

- 外部URL参照ゼロ (`src` / `href` / `url()`)。オフラインで開けない資料は配れない
- スライド内に `<script>` を置かない。ビューアは `sandbox` 付き iframe で読み込む
- 各スライドに CSP メタタグを残す
- `<title>` は主張を言い切る一文。ビューアの一覧とスクリーンリーダーがこれを読む
- `lang="ja"` を設定する

## 数値の外し方

上の値は「迷ったときの初期値」であって、守ること自体が目的ではない。
外す条件は1つだけ: **外した結果、伝わりやすくなったと説明できること。**
説明を deck.md の `accepted` に書けば、それは契約の一部になり、
以降のラウンドで批評担当が蒸し返さない。書かずに外したものは、ただの逸脱として直される。
